Minhas Habilidades

HTML

Criação da arquitetura e estrutura base para sites e aplicações web, utilizando HTML5 para garantir código limpo, organizado e bem indexado.

CSS

Estilização de interfaces web com foco na harmonia visual, utilizando combinações de cores, tipografia moderna e composição de layout para proporcionar uma boa experiência de navegação.

Lógica de Programação

Construção de pensamento analítico e raciocínio algorítmico para decompor problemas complexos e transformá-los em soluções estruturadas e eficientes através do código.

Design

  • Prototipagem & Wireframing: Criação de telas e fluxos de navegação interativos no Figma.
  • Design de Interfaces: Construção de layouts intuitivos, organizados e focados na usabilidade do usuário (UI/UX).
  • Foco na Experiência do Usuário: Garantia de navegação fluida, acessível e otimizada.

Redes e Comunicação

Configuração, administração e gerenciamento de sistemas operacionais voltados para redes, garantindo conectividade segura, roteamento eficiente, comunicação entre nós e gerenciamento centralizado de recursos.

Banco de Dados

Projeto e estruturação de bancos de dados relacionais, desde a análise conceitual com Diagramas Entidade-Relacionamento (DER) até o esquema lógico, garantindo integridade, normalização e eficiência no armazenamento das informações.
